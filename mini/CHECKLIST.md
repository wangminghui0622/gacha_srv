# M16 微信开发者工具走查清单（边界门 D8）

> 前置：服务端已按 run_all.sh 头注顺序启动（网关 http://127.0.0.1:9310）；
> 微信开发者工具导入 `mini/dist/build/mp-weixin`（project.config.json 已带 AppID wxefdb142d7e5a5d34，可直接导入；urlCheck 已关）。
> 构建：`npm run build:mp-weixin`；类型：`npm run type-check`；H5 兜底演示：`npm run build:h5`。
> M16a 核心闭环 + M16b 全玩法页（六玩法 + 活动中心/转盘 + 券中心 + 任务中心）。

## M16a 核心闭环

- [ ] **登录**：启动落在登录页；微信 tab 默认选中；点「微信一键登录」→ uni.login 取 code → POST /auth/wechat/login → 成功 toast + 进首页（未绑定 1013 时 toast 展示后端 msg，可走手机号/账号兜底）
- [ ] **登录兜底**：手机号验证码登录（60s 倒计时重发）；账号登录；注册后自动登录
- [ ] **免登录**：登录态有效时重新打开小程序 → 直接进首页（不闪登录页）
- [ ] **首页**：宝箱列表（3 盒、价格、售罄标记）；marquee 滚动中奖（需先有高档/限量中奖记录，可用 curl 造一条；掩码显示用户 id）；玩法宫格 8 格逐格可点（见 M16b 逐玩法走查）；下拉刷新
- [ ] **详情**：概率公示（条目名/概率/剩余库存，-1 显示不限量，0 显示售罄）；售罄盒禁购
- [ ] **购买**：报价面板（原价/券抵扣/积分抵扣/实付）；券选择器与积分开关互斥；确认弹窗；提交 → 轮询 → 开奖动画 → 揭晓（中奖 🎉/谢谢参与 🍀）；揭晓后余额已刷新
- [ ] **揭晓后**：中奖时「去仓库」可见；「去记录」可见新记录；「再抽一次」同幂等键重试（后端幂等返回同单号）
- [ ] **我的**：资料卡（昵称/用户名）；余额；充值入口；记录/仓库入口；券中心入口（见 M16b）；退出登录（确认弹窗 → 回登录页）
- [ ] **充值**：金额输入 → 成功 toast + 回「我的」余额更新（模拟通道，D5）
- [ ] **记录**：分页 + 上拉加载（不一次性全量）
- [ ] **仓库**：中奖物品列表（来源盒/时间）
- [ ] **401 失效**：清掉 storage 里的 gacha_token 后任意操作 → 自动跳登录页

## M16b 玩法宫格（首页 → 8 格逐一点击）

- [ ] **活动中心**（🏆）：签到（已签灰态/未签可点，成功弹层展示奖品+连续天数）；兑换码（输入→查询预览奖品/次数→兑换，幂等键按 campaignKey:code 复用）；转盘卡显示剩余次数，点「去抽奖」进转盘页
- [ ] **转盘**（从活动中心进入）：预览槽位渲染转盘（CSS 扇形拼接）；点「抽奖」→ 2.8s 减速动画落在中奖槽位（指针 12 点方向对齐槽位中心）→ 中奖弹窗；剩余次数-1；底部槽位说明列表（色点/标签/奖品）；同一次抽奖失败重试复用幂等键
- [ ] **挖宝箱**（⛏️）：宝箱选择（种子 1 号）→ 报价（含「全挖」开关/数量）→ 格子棋盘点选（💎 已挖/✦ 选中）→ 确认挖宝 → 轮询 → 揭晓动画 → 奖品列表；结果页可继续/换箱/回格子；底部挖宝记录（时间/格号/奖品）
- [ ] **满车**（🚗）：座位网格（4 座，已占显示 *** 后四位、已出发显示整车奖）；选座 → 报价确认弹窗 → 购座 SAGA → 轮询 → 揭晓（🎁 常规奖）；满座触发整车开奖（👑 LUCKY/🎁 NORMAL 整车奖每人一份）；底部购座记录
- [ ] **扭蛋**（🥚）：特别奖进度（🏆 LAST/⭐ MVP/🍀 分阶段 LUCKY，sent/quantity 进度条）；余票/参与人数；抽数选择（1/2/3/包尾）→ 购抽 → 轮询 → 揭晓（常规奖 + 特别奖高亮 dashed 框）；底部抽奖记录（含条目标题、计数、价格）
- [ ] **连击链**（⚡）：全局奖槽 chips；共享奖池（🎯 COMBO_TIER 进度条/🔥 空击连击/💫 中奖连击阈值）；我的连击；购票（已上车/已结算禁用）→ 轮询 → 揭晓；底部购票记录（车号）
- [ ] **拼团抽**（👥）：余注/目标/我的注数/参与人数；幸运奖进度卡（🍀）；下注数量（1/2/3/包尾）→ 确认 → 轮询 → 揭晓；底部下注记录
- [ ] **记忆翻牌**（🃏）：配置载入（回合数/价格/奖池/面具/背板预设）；无会话 → 命运抽签（首签 + 可选次签）；翻牌对局（手牌格子点选 ≤2 → apply；第二轮中奖自动命运抽）；回合状态 chips（进行中/已完成/已跳过）；完成 → 结算弹层（总对数/奖品/finalHash 前 16 位/冠军掩码）；购买 SAGA（外观 PUT + 购买，幂等键同次复用）；会话 resume（重进页面从 storage `mm_session_1` 恢复；已结算清键）；跳过需确认弹窗
- [ ] **任务中心**（📋，宫格第 8 格）：签到卡（连续天数/进度）；任务列表（状态 chip：进行中/可领取/已完成；进度文案按 metric；可领取才可点）；通行证卡（XP 进度条/Lv；免费/尊享槽位领取，本地已领记忆）；会员卡（累计消费/档位领取）；领取成功 toast
- [ ] **券中心**（我的 → 🎟️ 入口）：可领取模板（面值/门槛文案/领取按钮，已领灰态）；我的券（状态 chip 1-4 + 有效期 + 去使用 → 切回首页 tab）

## 已知限制（非缺陷）

- tabBar 文案（首页/我的）与页面导航标题为 pages.json 静态中文（微信 tabBar 不支持运行时 i18n；en-US 词条已就位，切语言 UI 与 web 一致未提供）
- 转盘为纯 CSS 扇形拼接（D4 改 CSS，偏离 canvas 方案）：WXSS 无 conic-gradient；槽位 <3 时隐藏转盘只留槽位说明（tan 发散，种子 ≥4 槽不受影响）
- 玩法格数 8 个固定（设计 D4），新增玩法需同步 pages.json 注册
- 服务端未改一行（M16 只动 mini/；老服务进程可直接复用）
